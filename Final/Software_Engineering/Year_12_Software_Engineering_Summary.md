# Year 12 Software Engineering — Definitions Summary

> **Scope:** Definitions for the three Year 12 topics: Programming for the Web, Software Automation, and Secure Software Architecture. Each topic has its own section; this is a terminology reference, not a blended topic note. Use the linked topic notes for fuller explanations and examples. Regression entries give model-use guidance, not calculations.

<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>JavaScript</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Programming language used to add behaviour and interaction to web pages.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Behaviour and logic.</td></tr>

<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Framework</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A reusable set of tools and conventions that provides a structure for building software.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A coding toolkit, not a content editor.</td></tr>

<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>MVC</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Model–View–Controller: an architecture separating data and logic, the user interface, and request handling.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Separates responsibilities within an application.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Model</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">In MVC, the component responsible for data and business logic.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Not the user interface.</td></tr>

<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Relational database</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A database that organises related data into tables of rows and columns, linked by keys.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Structured tables, rather than one unlinked text file.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>SQL</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Language used to query and manipulate relational databases.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Used to express database operations.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Object-Relational Mapping (ORM)</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A layer that maps database tables, rows and columns to program classes, objects and properties.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Lets code work with objects instead of writing every query as raw SQL.</td></tr>

### 1.2 Networks and protocols

<table style="border-collapse:collapse;width:100%;font-size:14px;margin:8px 0;">
<thead><tr><th style="border:1px solid #bdc1c6;padding:6px 10px;text-align:left;background:#e8eaed;color:#000000;font-weight:600;">Term</th><th style="border:1px solid #bdc1c6;padding:6px 10px;text-align:left;background:#e8eaed;color:#000000;font-weight:600;">Definition</th><th style="border:1px solid #bdc1c6;padding:6px 10px;text-align:left;background:#e8eaed;color:#000000;font-weight:600;">Quick distinction</th></tr></thead>
<tbody>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Network topology</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">The physical or logical arrangement of devices and connections in a network.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Describes arrangement, not the device's job.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Star topology</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Every device connects to a central device.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Central connection point.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Bus topology</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Devices share one main line, terminated at both ends.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">One shared backbone.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Ring topology</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Devices form a circular path, with data travelling around the ring.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Circular path, unlike a central star.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Mesh topology</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Devices have multiple interconnections, giving data more than one possible path.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Multiple paths between devices.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Hybrid topology</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A network arrangement combining two or more topology types.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Combines topologies.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Wireless topology</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A network arrangement that uses wireless links rather than physical cabling.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">No physical cabling; devices still form a network arrangement.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Hub</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A basic device that broadcasts incoming data to all connected devices.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Broadcasts to all; a switch targets a device.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Switch</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A network device that forwards data to the intended device on a local network.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Targets the recipient, unlike a hub.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Router</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A device that forwards data between networks and chooses a route.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Connects networks, often to the internet.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Bridge</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A device that connects two networks of the same type.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Same-type networks; a gateway joins different types.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Gateway</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A device or system that connects different networks and can translate between protocols.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Different network types; a bridge joins similar ones.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>MAC address</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A hardware identifier associated with a network interface.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Identifies hardware; an IP address identifies its network location.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>IP address</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">An address used to identify a device's location on an IP network.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Can change with the network connection; unlike a hardware MAC address.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>DNS</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Domain Name System: translates domain names into IP addresses; the common DNS service port is 53.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Finds an address; DHCP assigns network addresses.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>DHCP</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Dynamic Host Configuration Protocol: automatically provides network settings, such as an IP address.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Assigns settings; DNS resolves names.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Packet switching</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A method of sending data in packets that may travel by different routes and arrive out of order.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">TCP reassembles reliable, ordered data delivery.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Network protocol</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">An agreed set of rules that devices use to communicate.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A protocol defines communication; a port identifies an endpoint/service.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Port</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A numbered endpoint used to direct network traffic to a service or application.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">TCP itself has no fixed service port; services use ports.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>TCP / TCP-IP</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Transmission Control Protocol provides reliable, ordered transport by retransmitting lost data; TCP/IP is the protocol suite used for internet communication.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Transport-layer delivery, not a web application protocol like HTTP.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>HTTP</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Hypertext Transfer Protocol: a protocol for requesting and transferring web resources; its default port is 80.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">HTTP is not encrypted by itself.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>HTTPS</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">HTTP protected by TLS for secure web communication; its default port is 443.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Encrypted web traffic, unlike plain HTTP.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>FTP / SFTP</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">File Transfer Protocol transfers files (port 21); SFTP transfers files securely over SSH (port 22).</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">SFTP is the secure option.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>SMTP / POP3 / IMAP</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Email protocols: SMTP sends mail (port 25); POP3 retrieves mail (port 110); IMAP synchronises mail with a server (port 143).</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">SMTP sends; POP3 and IMAP retrieve or synchronise.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>SSH</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Secure Shell: a protocol for secure remote access to a server, commonly using port 22.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Secure remote login; SFTP uses SSH.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>SSL / TLS</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Protocols for protecting data sent between a website and a user; TLS is the more secure replacement for SSL.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">TLS replaced the older SSL protocol.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>CORS</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Cross-Origin Resource Sharing: a browser rule controlling requests from one origin to another.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Browser policy, not a firewall.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>tcpdump</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A command-line tool for capturing and inspecting network packets.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Used to inspect traffic, not to route it.</td></tr>
</tbody></table>

### 1.3 Big data and web standards

<table style="border-collapse:collapse;width:100%;font-size:14px;margin:8px 0;">
<thead><tr><th style="border:1px solid #bdc1c6;padding:6px 10px;text-align:left;background:#e8eaed;color:#000000;font-weight:600;">Term</th><th style="border:1px solid #bdc1c6;padding:6px 10px;text-align:left;background:#e8eaed;color:#000000;font-weight:600;">Definition</th><th style="border:1px solid #bdc1c6;padding:6px 10px;text-align:left;background:#e8eaed;color:#000000;font-weight:600;">Quick distinction</th></tr></thead>
<tbody>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Big data</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Large or complex datasets characterised by the six V's: volume, velocity, variety, veracity, value and variability.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Not defined by size alone.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Volume</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">The quantity of data.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">How much?</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Velocity</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">The speed at which data is generated and must be processed.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">How fast?</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Variety</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">The range of data formats, such as text, images, video and sensor readings.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">What forms?</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Veracity</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">How trustworthy and accurate the data is.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Can it be trusted?</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Value</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Whether the data can produce useful insight.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Is it useful?</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Variability</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">How the meaning or structure of data changes over time.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Does meaning or format change?</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Data</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Raw facts or values without context that explains what they mean, such as individual login timestamps.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Raw input, not interpreted meaning.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Information</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Data organised and given context so it answers a question, such as a chart showing peak login hours.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Meaningful summary, not yet an inferred insight.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Knowledge</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">An insight or pattern inferred by analysing information, such as users often logging in after school.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">An inferred pattern, not the decision itself.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Understanding</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Applying knowledge with context to choose or justify an action, such as scheduling extra server capacity during the after-school peak.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">The frameworks differ: Enterprise Computing's knowledge definition includes using experience to support a decision; SE has a separate Understanding stage. EC mentions wisdom only as context. Keep each course's labels.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Data mining</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Automated computational analysis of large datasets to discover meaningful patterns, trends, relationships, clusters or anomalies that are difficult to spot in individual records. Findings can inform predictions or decisions, but a pattern or correlation alone does not establish causation. <tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Hidden layer</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A layer between input and output that processes signals through connected nodes.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Internal processing, not the input or final output.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Output layer</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">The layer that produces the network's result.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Final prediction or response.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Decision tree</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A model that splits data into branches using rules based on input features.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Its rule path is easier to inspect than a neural network's internal patterns.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Training cycle</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">The phase where a model learns from data with known responses and determines internal values.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Learns from training data before use on new inputs.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Execution cycle</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">The phase where a trained model uses its learned values to produce an output for input data.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Applies the trained model; it does not establish the learned values.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Weighting</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A learned numeric value on a connection that controls how strongly an input signal contributes to the next neuron. A larger weight gives that connection more influence, not a firing threshold.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Connection influence; the threshold is the activation cut-off for the combined signal.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Threshold</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A cutoff applied after input signals have been combined. In the simplified model used here, the neuron produces an output when the combined signal exceeds that cutoff.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">The firing condition; weightings determine the influence of individual incoming connections.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Overfitting</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">When a model learns training data too precisely, including noise, and performs poorly on unseen data.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Good training fit does not guarantee generalisation.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Pruning</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Removing branches from a decision tree to reduce overfitting and unnecessary complexity.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Simplifies a tree after or during model building.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Dataset bias</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Systematic skew or missing representation in the data used to train a model.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Bias in the dataset, distinct from bias in how people collect or label it.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Human bias</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Assumptions or preferences that influence how people collect, label or interpret data.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Can enter a dataset through human choices and labelling.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Stimulus</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">An event or cue that triggers a reaction.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">The trigger; a response is the reaction.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Response</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A behavioural or physical reaction to a stimulus.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">The reaction, not the triggering event.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Arousal</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">The level of mental and physical activation or alertness a person experiences.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A state of activation, not an action by itself.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Impulse</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">An immediate urge to act, often before considering consequences.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">An urge; regulation is the process of managing it.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Regulation</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Managing impulses, emotions or behaviour in response to a situation.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Control or modulation, not the initial urge.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Psychological regression</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A return to earlier behaviour or coping patterns, sometimes under stress.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Not a regression algorithm used to predict values.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Conditioning</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Learning an association between events or between a situation and a response.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">An association learned through experience.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Habituation</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A reduced response after repeated exposure to a familiar stimulus.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Response decreases with repetition.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Sensitisation</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">An increased response after exposure to a stimulus, particularly after repeated or intense exposure.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Response increases, unlike habituation.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Fight–flight–fawn response</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Common reactions to perceived threat: confront it, escape it, or appease to reduce danger.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Different possible responses to threat.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Acute stress response</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">An immediate mental and physical reaction to a perceived threat or demand.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Short-term reaction to an immediate stressor.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Stress</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A mental and physical response to perceived demands or pressures.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">The acute stress response is the immediate, short-term reaction.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Cultural protocols</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Culturally informed rules and expectations that shape appropriate interaction and use of information.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Context-specific norms, not universal technical rules.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Belief system</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A connected set of beliefs and assumptions that influences how a person interprets events and makes choices.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Can influence how people create or interpret training data.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Astroturfing</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Creating fake accounts or activity to make a campaign appear to have genuine grassroots support.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">Manufactured support, not organic public opinion.</td></tr>
<tr><td style="border:1px solid #bdc1c6;padding:6px 10px;"><b>Goldilocks Zone</b></td><td style="border:1px solid #bdc1c6;padding:6px 10px;">The described balance between impulsivity and self-regulation that technology can seek to influence.</td><td style="border:1px solid #bdc1c6;padding:6px 10px;">A psychology concept in the unit, not an ML algorithm.</td></tr>
</tbody></table>
